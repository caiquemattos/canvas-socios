# Canvas de Sócios

Página pública de alinhamento entre sócios, baseada no livro *Academia de Sócios*, de Anderson Godz.

- `index.html`: a página publicada no GitHub Pages.
- `Code.gs`: o script do Google Apps Script que grava as respostas numa planilha privada. **Não suba este arquivo para o repositório**: ele fica dentro da planilha.

## Como funciona

- Cada participante escreve o nome e responde. As respostas são salvas automaticamente na planilha do organizador.
- Cada pessoa recebe um link pessoal (`?c=...`) para continuar depois, em qualquer aparelho.
- A visão do organizador fica em `.../#organizador` e pede a chave guardada em `ADMIN_KEY`, nas propriedades do script.
